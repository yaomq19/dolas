# Dolas引擎 DX12 迁移计划

## 迁移目标
- 完全移除DX11，迁移至DX12
- 实现中层级RHI封装（暴露CommandList、PSO、RootSignature等核心概念，自动管理描述符堆）
- 升级至DXC编译器（HLSL 6.0+）
- 支持多线程命令记录

### 1.2 创建RHI抽象接口
**新文件**: `src/engine_runtime/dolas_function/public/include/render/rhi_interface.h`

定义核心RHI接口：
```cpp
namespace Dolas {

// 核心RHI接口（DX12后端实现）
class IRHIDevice {
public:
    virtual ~IRHIDevice() = default;
    virtual ID3D12Device* GetNativeDevice() = 0;
    virtual IDXGIFactory4* GetDXGIFactory() = 0;
};

class IRHICommandQueue {
public:
    virtual ~IRHICommandQueue() = default;
    virtual void ExecuteCommandLists() = 0;
    virtual void Signal(Fence fence, UINT64 value) = 0;
    virtual void WaitForFence(Fence fence, UINT64 value) = 0;
};

class IRHICommandAllocator {
public:
    virtual ~IRHICommandAllocator() = default;
    virtual ID3D12CommandAllocator* GetNative() = 0;
    virtual void Reset() = 0;
};

class IRHICommandList {
public:
    virtual ~IRHICommandList() = default;
    virtual ID3D12GraphicsCommandList* GetNative() = 0;
    virtual void Reset(IRHICommandAllocator* allocator) = 0;
    virtual void Close() = 0;
    virtual void ResourceBarrier(...) = 0;
    virtual void SetGraphicsRootSignature(...) = 0;
    virtual void SetPipelineState(...) = 0;
    virtual void SetDescriptorHeaps(...) = 0;
    virtual void SetGraphicsRootDescriptorTable(...) = 0;
    virtual void SetGraphicsRootConstantBufferView(...) = 0;
    virtual void SetGraphicsRootShaderResourceView(...) = 0;
    virtual void IASetPrimitiveTopology(...) = 0;
    virtual void IASetVertexBuffers(...) = 0;
    virtual void IASetIndexBuffer(...) = 0;
    virtual void RSSetViewports(...) = 0;
    virtual void RSSetScissorRects(...) = 0;
    virtual void OMSetRenderTargets(...) = 0;
    virtual void ClearRenderTargetView(...) = 0;
    virtual void ClearDepthStencilView(...) = 0;
    virtual void SetBlendFactor(...) = 0;
    virtual void SetStencilRef(...) = 0;
    virtual void DrawInstanced(...) = 0;
    virtual void DrawIndexedInstanced(...) = 0;
};

class IRHIFence {
public:
    virtual ~IRHIFence() = default;
    virtual void Signal(UINT64 value) = 0;
    virtual void Wait(UINT64 value) = 0;
    virtual UINT64 GetCompletedValue() = 0;
};

}
```

## 关键技术决策

### 1. 描述符堆管理策略
- **SRV/CBV/UAV堆**: Shader-visible heap，每帧一个，用于GPU访问
- **RTV堆**: Non-shader-visible，按需分配
- **DSV堆**: Non-shader-visible，按需分配

### 2. 命令列表分配策略
- **主线程**: Graphics命令列表
- **工作线程**: 每个线程独立的CommandAllocator
- **池大小**: 根据Swap Chain缓冲区数量（通常是3）

### 3. 资源状态管理
- 使用Resource Barrier自动跟踪资源状态
- 在渲染Pass开始前转换资源状态
- 提供简化接口（如`TransitionToRenderTarget`）

### 4. Root Signature设计
- **方案1**: 全局单一Root Signature（简单但不够灵活）
- **方案2**: 每个材质独立Root Signature（灵活但开销大）
- **推荐**: 混合方案 - 常用Root Signature池 + 材质特定Root Signature

### 5. 多线程同步
- 使用Fence同步GPU-CPU
- 使用Event同步线程间命令列表提交
- 每帧等待GPU完成后再开始下一帧

## 风险与缓解措施

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| DX12复杂度高 | 开发周期延长 | 使用中层级封装，隐藏细节 |
| 描述符堆管理错误 | 显存泄漏 | 实现自动管理器，验证生命周期 |
| 资源状态冲突 | 渲染错误 | 自动Barrier跟踪，调试工具支持 |
| 多线程死锁 | 崩溃 | 使用已有的ThreadPool，避免手动锁 |
| 着色器迁移错误 | 黑屏 | 逐步迁移，使用RenderDoc调试 |
