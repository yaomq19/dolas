# Dolas 编辑器开发路线图

## 项目概述

本文档详细规划了 Dolas 游戏引擎编辑器的开发计划，基于现有的 ImGui 框架进行增强。开发分为多个阶段，优先实现资源管理、场景编辑和场景保存/加载等核心功能。

**技术栈**：
- ImGui + ImGuizmo（3D Gizmo 库）
- DirectX 11 渲染后端
- C++20
- CMake 构建系统

**UI 风格**：类似 Unity/Unreal 的深色主题专业编辑器风格

```cpp
// src/engine_runtime/dolas_function/public/include/editor/ContentBrowser.h
class ContentBrowser
{
public:
    void Render();
    void Refresh();

    std::string GetSelectedPath() const;

private:
    void RenderDirectoryTree();
    void RenderFileList();
    void RenderToolbar();
    void RenderPreviewPanel();

    void ScanDirectory(const std::string& path);
    FileType GetFileType(const std::string& extension) const;
    const char* GetFileTypeIcon(FileType type) const;
    const ImVec4& GetFileTypeColor(FileType type) const;

    bool NavigateTo(const std::string& path);
    void NavigateBack();
    void NavigateForward();
    void NavigateUp();

    std::string m_base_path = "content/";
    std::string m_current_path;
    std::string m_selected_path;

    std::vector<FileInfo> m_files;
    std::vector<std::string> m_nav_history;
    size_t m_nav_index = 0;

    bool m_grid_view = true;
    float m_icon_size = 80.0f;
    float m_spacing = 10.0f;
};

enum class FileType
{
    Folder,
    Mesh,
    Texture,
    Material,
    Shader,
    Scene,
    Camera,
    Unknown
};

struct FileInfo
{
    std::string name;
    std::string path;
    FileType type;
    UInt64 size;
    std::string modified_time;
    bool is_directory;
};
```
