# 技能说明
本技能用于监听用户的自然语言指令，并将其映射到项目根目录 `scripts/` 文件夹下的对应批处理或 Python 脚本，以实现自动化的工程管理。

## 1. 编译与构建
* **触发条件**：当用户提到“构建”、“构建项目”、“编译项目”等词语的时候。
* **执行指令**：执行 `scripts/build-debug.bat`
* **执行环境**：项目根目录
* **期望反馈**：执行完毕后，将编译过程的控制台输出结果返回给用户。

## 2. 项目生成与配置
* **触发条件**：当用户提到“生成项目”、“重新CMake”等词语的时候。
* **执行指令**：执行 `scripts/setup.bat`
* **执行环境**：项目根目录
* **期望反馈**：执行完毕后，将 CMake 生成的项目配置结果返回给用户。

## 3. 代码行数统计
* **触发条件**：当用户提到“统计项目代码行数”相关词语的时候。
* **执行指令**：执行 `python scripts/count_loc.py`
* **执行环境**：项目根目录
* **期望反馈**：执行完毕后，提取脚本输出的统计数据并清晰地向用户展示。
